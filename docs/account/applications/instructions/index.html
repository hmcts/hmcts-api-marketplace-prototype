Get an access token

Request a token from Microsoft Entra ID with the OAuth 2.0 client credentials flow:

curl --request POST \
  --url  \
  --header 'Content-Type: application/x-www-form-urlencoded' \
  --data grant_type=client_credentials \
  --data client_id= \
  --data 'client_secret=' \
  --data scope=
